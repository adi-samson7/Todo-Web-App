📝 Todo Web App
A simple and intuitive Todo Web Application built with Streamlit. This app helps you organize tasks, track progress, and stay productive — all in a clean, user-friendly interface.

🚀 Live Demo:
https://adi-samson7-todo-web-app-web-evde2q.streamlit.app/

📌 Features
➕ Add tasks with ease
🗑️ Remove tasks when done
🔄 Real-time updates without page refresh
🧠 Minimal and intuitive UI

🧱 Built With
Streamlit — For UI and web deployment
Python — Backend logic


🛠️ How It Works
Enter a task in the input field.
Click Enter to save it to your list.
Mark tasks as done which deletes them when completed.
Changes update instantly in the UI.

🧰 Requirements
Python 3.7+
Streamlit

💻 Installation
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name
pip install -r requirements.txt
streamlit run gray.py


⚙️ Deployment
The app is deployed using Streamlit Community Cloud.
